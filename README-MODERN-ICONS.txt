MoveGo visual refresh — Modern SVG icons

Added frontend/js/modern-icons.js and frontend/css/modern-icons.css. All 20 passenger pages now load the modern icon system. Existing design and data flow were retained. The icons are local vector graphics that do not need an internet connection. Dynamic ride-option and notification icons are refreshed automatically. The icon system does not implement new backend functionality.
